# Dx 书写五则（Diagnosis Normalization Rules）

> 继承自 `legacy/SKILL.md`（2026-09-30 定稿），由 `src/vet_case_extractor/normalization/dx.py` 与 `validation/semantic.py` 执行与校验。

## 五条规则

1. **物种前置、不空格**：
   - 格式为 `物种+疾病名称`，如 `犬血支原体感染`、`猫弥散性虹膜黑色素瘤`、`马产后败血症/子宫炎`。
   - 物种与疾病名之间**不加空格**。
   - **整条 `Dx` 只在最前面写一次物种**，后续并列/继发诊断不再重复写物种。
   - 物种词表见 `config/extraction_rules.yaml`（涵盖 `犬、猫、马、驴、骡、牛、奶牛、水牛、牦牛、山羊、绵羊、羊、猪、美洲驼、羊驼、骆驼、雪貂、兔、豚鼠、仓鼠、龙猫、刺猬、水貂、狐、鹿、猴、虎、狮、大熊猫、鸡、鸭、鹅、鸽、鹦鹉、鸟、禽、龟、蛇、蜥蜴` 等 46+ 种）。

2. **主病在前**：
   - 主要 / 最重要 / 致病核心诊断写在第一位；次要、并发、继发诊断依次排后。

3. **中文分号间隔**：
   - 多病、并发、继发诊断一律使用中文分号 `；` 分隔，**禁止使用逗号罗列**或把独立次要诊断塞入括号。
   - 继发/并发关系如原文明确，显式保留「继发」「并发」字样。
   - 示例：`犬骨肉瘤（肱骨近端）；肺转移`、`猫膀胱结石；尿道梗阻；继发急性肾损伤`。

4. **括号四分法（去留判别）**：

   | 括号内容类型 | 处置方式 | 示例 |
   |---|---|---|
   | **解剖部位 / 独立限定词** | **保留在病名后**（全角括号） | `犬 骨肉瘤（肱骨近端）` → `犬骨肉瘤（肱骨近端）` |
   | **解读性 / 化验指标描述 / 鉴别说明** | **整段移入 `备注`**，`Dx` 只保留病名 | `犬 创伤后肝细胞损伤（ALT/AST 一过性升高；非原发性肝胆疾病）` → `Dx=犬创伤后肝细胞损伤`，括号内容入 `备注` |
   | **同一疾病的更规范医学名称** | **用括号内规范名替换外层俗称**并去括号 | `犬 皮质类固醇性肝病（医源性肾上腺皮质机能亢进）` → `犬医源性肾上腺皮质机能亢进` |
   | **括号内继发句混有症状/体征** | **提取真正诊断并用 `；` 拼接，丢弃非诊断症状**（厌食、应激、消瘦、发热、呕吐等） | `马 产后败血症/子宫炎（继发肌肉损伤、厌食、应激）` → `马产后败血症/子宫炎；继发肌肉损伤` |

5. **缩写规范**：
   - 缩写遵循「中文全称在前 + 全角括号内放英文缩写」，如 `犬颈椎C4~C5水合髓核脱出（HNPE）`。
   - 原文标准病名照录，不擅自意译或篡改。

---

## 审计要求

- Raw 层字段 `diagnosis_raw` 始终保留原文诊断表述。
- Normalized 层字段 `diagnosis_normalized` 记录按五则规范化后的结果，所有变动写入 `CaseRecord.normalization_changes`。
- 若遇到无法自动分类的复杂括号说明，系统保留信息并在 QA 报告中标记人工复核。

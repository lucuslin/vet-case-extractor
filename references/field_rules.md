# 字段抽取口径与边界规范（Field Extraction Rules）

> 继承并工程化自 `legacy/SKILL.md`，对应规则编号 `R-01 ~ R-11`。

## 核心纪律

1. **严格取自原文**：所有事实字段内容严格依据原文，不编造、不改写、不推理、不翻译。
2. **缺失留空**：原文未提供某字段（如教学型病例无治疗、无随访）时，直接留空字符串 `""`，**严禁**填写 `无`、`未提及`、`未见`、`不适用`、`N/A`、`—` 等占位符。
3. **双层保留（Raw / Normalized）**：
   - Raw 层保留逐字原文（仅允许合并段内硬换行与清理多余空格）。
   - Normalized 层应用 Rx 缩略语和 Dx 五则，并在 `normalization_changes` 中记录每条变更。

---

## 交付列口径

### 期刊病例（9 列，顺序固定）
`source | year | title | medical_history | medical_test | medical_treatment | Dx | follow-up | 备注`

### 扫描书籍 / 译著（7 列，删除 `source` / `year`）
`title | medical_history | medical_test | medical_treatment | Dx | follow-up | 备注`

## 各字段详细划分

| 字段 | 应包含内容 | 严禁混入 / 边界说明 |
|---|---|---|
| `source` | 仅填中文刊名（如 `中国兽医杂志`、`畜牧与兽医`）；仅在全文无中文刊名时填英文刊名。 | 书籍格式不输出此列。 |
| `year` | `发表年（收稿年）`（全角括号，如 `2023（2020）`）；无收稿日期或收稿年与发表年相同时仅填发表年（如 `2023`）。刊期年即发表年。 | 书籍格式不输出此列。 |
| `title` | 期刊：病例报告题名（默认同 PDF 文件名去 `.pdf`；合订本取目标文章精确题名）。书籍：`章节名 · 病例N 等级X`（如 `第二章 肝酶升高 · 病例1 等级1`）。 | 不得篡改原题；书籍等级须与页图及 `index.json` 一致。 |
| `medical_history` | 1. 信号量（物种、品种、年龄、性别/去势状态、体重）；<br>2. 主诉（CC）；<br>3. 现病史与既往史（PMH）；<br>4. **一般体格检查（PE）**：体温、脉搏、呼吸、CRT、BCS/体况评分、可视黏膜、心肺听诊、心杂音、腹部触诊、体表淋巴结等；<br>5. **外院/他院既往诊疗与诊断结论（Tier C）**；<br>6. 一文多病例拆行时，以 `病例N：` 开头区分。 | 不含本次就诊实验室/影像/神经学/专科检查；不含纯临床推理。 |
| `medical_test` | 1. 实验室检查（CBC、生化、尿检、血气、体腔液、PCR、基因检测等）；<br>2. 影像学检查（X线、超声、CT、MRI、超声心动图）；<br>3. **神经学检查客观发现**（本体感受、共济失调、UMN/LMN 症状、脑神经与脊髓反射）；<br>4. **专科检查**（眼科裂隙灯/眼压/房角镜/眼底检查、口腔专科检查、内镜等）；<br>5. **本次诊断性操作及其病理/细胞学结果**（穿刺活检、切除活检、存活动物开腹/开胸探查、离体切除标本肉眼及镜检）。 | 1. **不得混入一般体格检查**（原文连写「体格检查：… 实验室检查：…」时必须拆分）；<br>2. **不得混入临床推理/提示/神经学定位**（移至 `备注`）；<br>3. **不得混入死后剖检及死后病理**（移至 `follow-up`）。 |
| `medical_treatment` | 本次就诊实际实施的治疗方案、手术/处置细节及处方药物（剂量、途径、频次、疗程）。Normalized 层将途径与频次规范化为 `po/iv/im/sc` 与 `sid/bid/tid/qid`（如 `每日口服2次` → `po, bid`）。 | 1. **严禁混入任何随访/转归/复查/死亡/好转信息**（移至 `follow-up`）；<br>2. **严禁把「解析/讨论」中的假设性诊疗建议写成已实施治疗**；<br>3. 原文无治疗时必须留空。 |
| `Dx` | 诊断结论。Raw 层保留原文诊断；Normalized 层严格按 `references/dx_rules.md`「Dx 书写五则」整理。 | 不得加入非诊断症状；不得遗漏物种前缀。 |
| `follow-up` | 治疗后转归、复诊/回访时间线、康复/复发/安乐死/死亡信息，以及**全部死后剖检/尸检及伴随的死后组织病理学/细胞学/免疫组化/实验室检查结果**。 | 原文无随访与转归时留空。 |
| `备注` | 1. 从事实列剥离的临床推理、检验解读、神经学定位、病因推测（前缀 `【原文推理/解读剥离】`）；<br>2. 从 `Dx` 括号移出的解释性/化验描述性内容；<br>3. OCR 存疑说明、原书印刷异常标注（`原书/页图如此`）、合订本串扰提示、抽取不确定性说明。 | 不写模型内部调试日志。 |

## 三大特殊校准规则

### 1. 推理与客观事实分离（含 Tier C 保留）
- 凡含 `提示 / 符合 / 疑似 / 不排除 / 初步排除 / 由此推断 / 结合临床初步诊断 / 初诊考虑 / 初步诊断 / 初步怀疑 / 初步考虑 / 鉴别诊断不能排除 / 分析可能是 / 暂时排除 / 可能与 / 病变定位于` 的**纯推理/定位句**，剥离至 `备注`（前缀 `【原文推理/解读剥离】`），并清理残留病句碎片。
- **混合事实+推理句**（同句既有客观检查发现又有「提示/疑似」推断）：语义抽取阶段尽量只拆出推理半句；规则后处理绝不盲删客观事实，存在歧义时保留事实并标记 `review_required`。
- **Tier C 保留**：凡归属**他院 / 外院 / 转诊 / 主人 / 畜主 / 既往 / 来院前**的怀疑或既往诊断（如「外院怀疑口鼻瘘」「主人怀疑被咬伤」「4个月前外院切除肿物并诊断为纤维肉瘤」），属于病史背景，**原样保留在 `medical_history`**，不得剥离。

### 2. 本次诊断性操作 vs 既往史
- **本次就诊**：诊断性穿刺、活检、开腹/开胸探查取材及病理/细胞学 → `medical_test`。
- **来院前/外院**：既往手术、外院化验与诊断结论 → `medical_history`。

### 3. 死后剖检 vs 存活动物术中探查
- **死后剖检 / 尸检 / 安乐死后剖检**及伴随死后病理/涂片/免疫组化 → 全部归入 `follow-up`（若 `medical_test` 因此为空，属正常情况）。
- **存活动物术中探查**（如开腹探查见肠闭锁）及**存活手术切除后离体标本肉眼/病理检查** → 保留在 `medical_test`。
